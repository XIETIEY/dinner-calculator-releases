# 东方聚餐结算器

吃完饭，有人垫了餐费，有人付了饮料钱，还有人只参加了第二场。把每场的参与人员和垫付款记下来，东方聚餐结算器就会算出每个人该付多少、转给谁。算完可以把带收款码的结算长图发到群里，大家照着转账就行。

**[下载 Android 安装包](https://github.com/XIETIEY/dinner-calculator-releases/releases/latest)** · 支持 Android 10 及以上

## 能做什么

- **记录多笔垫付。** 一个人可以添加多笔订单，为每笔费用写备注。没垫钱的朋友也能加入均摊，金额留空即可。
- **多场聚会一起算。** 比如四个人吃饭、三个人续摊。每场由实际参加的人均摊，同一个人在不同场次的收付款合并计算。
- **自动安排转账。** 应用默认按最少转账次数生成收付款安排。也可以点开收款详情，查看谁需要付多少。
- **把结算结果发到群里。** 可以给收款人添加微信或支付宝收款码，把订单明细、转账安排和收款码导出到一张长图。
- **把常一起聚餐的朋友存进信息簿。** 保存昵称、标签和收款码，下次直接选入。也可以把选中的人员导出成资料图，发原图给朋友，对方从相册导入即可。
- **跟着角色试算一遍。** 在「关于应用」里打开「新手演示」，跟灵梦和魔理沙走一遍添加人员、录入订单和分享结算的流程。

## 第一次怎么用

1. 在「人员」页添加所有参与 AA 的朋友，把垫付金额录在对应的人名下。
2. 有多场活动时，点击「添加聚会」。同一位朋友参加多场，请用「从已有人员或信息簿选入」。
3. 在「结算」页核对收付款安排，按需添加收款码，点击「导出长图」分享。

## 安装与反馈

打开下载页，在 **Assets** 下下载 `dinner-calculator-2.8.9.apk`，再从 Android 手机的下载列表打开安装。手机如果提示授权，可按系统提示允许当前浏览器或文件管理器安装应用。

遇到问题或有功能建议，欢迎到 [Issues](https://github.com/XIETIEY/dinner-calculator-releases/issues) 反馈。描述问题时，可以附上 App 版本、手机型号、Android 版本和复现步骤。
